🕰️ JavaScript Universe Clock

🌌 Key Features

JS clock UI has a milliseconds hand. It also uses a neon/OLED look.

A toggle button allows the user to switch the "hour markers" between two distinct sets of PNG files:
🎨 figdesigns: Traditional numerals also serving as the default UI.
📜 jsconcepts: Core JavaScript concepts and related to it are displayed as Roman Numerals.

The background shifts automatically subtly between AM and PM modes.

Link: https://manjilj.github.io/jsclock/
